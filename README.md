# All Saints' Episcopal Church website

A lightweight static website for All Saints' Episcopal Church in Wolcott,
Connecticut. It uses plain HTML, CSS, and a few lines of JavaScript, so there
is no build step and no framework to maintain.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any small
static web server. The site can be published as-is with GitHub Pages.

## Site map

- `index.html` — homepage and essential Sunday information
- `visit.html` — first-visit guide, parking, and map
- `worship.html` — Sunday worship and Communion
- `parish-life.html` — parish-life overview
- `fellowship.html` — Sunday coffee fellowship
- `outreach.html` — choir and community outreach
- `prayer-garden.html` — public prayer garden
- `clergy.html` — clergy and parish leadership
- `contact.html` — contact details and map
- `style.css` — shared design and responsive styles
- `site.js` — accessible mobile navigation

## Updating the site

Content is intentionally kept in the HTML files. Service time, address,
phone, email, leadership, and footer information appear on multiple pages;
search the repository for the old value before changing one of these shared
details.

The design does not require images. Real, optimized parish photos can be
added later without delaying publication. Avoid stock or AI-generated images
that could be mistaken for the actual church or congregation.

## Before publishing

- Confirm the listed clergy and leadership roles are current.
- Confirm the prayer garden is open daily from dawn to dusk.
- Confirm service time, phone, email, street address, and mailing address.
- Test the site on a phone and run a Lighthouse accessibility check.
